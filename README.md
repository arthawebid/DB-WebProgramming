REKAPITULASI MATERI & CAPAIAN PEMBELAJARAN (PERTEMUAN 1 S.D. 16)

#### 1. Pertemuan 1: Pengantar Web Developer & Konfigurasi Lingkungan Kerja

* **Capaian yang Diharapkan:** Mahasiswa mampu menjelaskan cara kerja dasar web, mengidentifikasi fungsi spesifik HTML, CSS, JavaScript, dan PHP, serta menyiapkan lingkungan pengembangan lokal (*teks editor, web server* seperti XAMPP/Laragon, dan *browser*).


* **Materi:** Arsitektur *Client-Server*, *HTTP Request*, komponen utama web, dan instalasi *tools* pengembang.



#### 2. Pertemuan 2 & 3: Struktur Dasar dan Elemen Fundamental HTML

* **Capaian yang Diharapkan:** Mahasiswa mampu membangun halaman web statis dengan struktur yang logis dan semantik melalui penerapan elemen fundamental HTML (teks, paragraf, daftar, gambar, tautan).


* **Materi:** Struktur HTML5, *Heading*, *Paragraph*, *Hyperlink* (`<a>`), *Image* (`<img>`), *List* (`<ul>`, `<ol>`), serta elemen semantik (`<header>`, `<main>`, `<footer>`).



#### 3. Pertemuan 4: Dasar-dasar Styling dengan CSS

* **Capaian yang Diharapkan:** Mahasiswa mampu menerapkan aturan *styling* dasar pada halaman HTML untuk mengubah properti visual teks dan latar belakang menggunakan sintaks CSS (*selector* dan properti) serta memahami metode Inline, Internal, dan External.


* **Materi:** Analogi HTML & CSS, sintaks dasar CSS, metode penambahan CSS, *Selector* (Tag, Class, ID), serta properti warna dan tipografi teks.



#### 4. Pertemuan 5: Layouting dengan CSS Box Model dan Flexbox

* **Capaian yang Diharapkan:** Mahasiswa mampu menganalisis elemen HTML sebagai *Box Model* untuk mengelola spasi/dimensi, serta mengimplementasikan teknik *layouting* modern menggunakan *Flexbox* dalam tata letak satu dimensi.


* **Materi:** Komponen *Box Model* (*content, padding, border, margin*), properti *display*, serta tata letak modern *Flexbox* (`justify-content`, `align-items`).



#### 6. Pertemuan 6: Pengenalan JavaScript dan Selector DOM

* **Capaian yang Diharapkan:** Mahasiswa mampu menjelaskan peran JavaScript di sisi klien, mengintegrasikannya ke HTML, serta memilih elemen spesifik berdasarkan ID, Class, dan Tag untuk interaktivitas.


* **Materi:** Peran JavaScript sisi klien, tag `<script>`, DOM Selector (`getElementById`, `querySelector`), *Event Listener*, dan logika kondisional `if/else`.



#### 7. Pertemuan 7: Dasar-Dasar PHP dan Variabel Dinamis

* **Capaian yang Diharapkan:** Mahasiswa mampu menulis kode sintaks dasar PHP, mendeklarasikan variabel, dan mengintegrasikannya untuk menampilkan data secara dinamis (termasuk percabangan, perulangan, array, dan format JSON).


* **Materi:** Tag PHP, variabel dinamis (`$`), perintah `echo`, percabangan `if-elseif-else`, perulangan *for/foreach*, serta konversi array ke format JSON.



#### 8. Pertemuan 8: Ujian Tengah Semester (UTS)

* **Capaian yang Diharapkan:** Mengevaluasi pemahaman mahasiswa secara komprehensif terhadap materi Pertemuan 1 sampai 7 melalui proyek perorangan/kelompok.


* **Materi:** Implementasi terpadu HTML, CSS, Flexbox, JavaScript DOM, dan PHP dasar.



#### 9. Pertemuan 9: Ekosistem WordPress & Theme (CMS)

* **Capaian yang Diharapkan:** Mahasiswa mampu menjelaskan arsitektur WordPress, melakukan instalasi di server lokal, serta mengoperasikan Dashboard untuk menginstal tema.


* **Materi:** Pemisahan konten dan desain, arsitektur CMS WordPress (Core, Database MySQL, Theme, Plugin), serta instalasi tema Astra.



#### 10. Pertemuan 10 & 11: Konfigurasi Dashboard & Identitas WordPress

* **Capaian yang Diharapkan:** Mahasiswa mampu menavigasi Dashboard untuk kustomisasi awal, meliputi aktivasi tema, konfigurasi identitas dasar website (*Site Title, Tagline, Site Icon*), dan palet warna.


* **Materi:** WordPress *Customizer*, aturan aset visual Favicon (508x512 px PNG transparan), serta penerapan palet warna berbasis *Hex Code*.



#### 11. Pertemuan 12 & 13: Struktur Halaman & Instalasi Page Builder

* **Capaian yang Diharapkan:** Mahasiswa mampu mengatur konfigurasi dasar situs yang mencakup struktur halaman statis, hierarki menu navigasi, dan instalasi plugin *page builder*.


* **Materi:** Perbedaan *Pages* vs *Posts*, pengaturan *Static Homepage*, manajemen menu navigasi (*drag-and-drop*), serta instalasi plugin Elementor.



#### 12. Pertemuan 14 & 15: Manajemen Konten (Page & Post) dan Plugin Pendukung

* **Capaian yang Diharapkan:** Mahasiswa mampu mengelola konten dasar situs dengan membedakan Page dan Post, serta memperluas fungsionalitas melalui plugin pendukung (seperti *The Post Grid* dan *Shortcode*).


* **Materi:** Pengelolaan artikel dinamis (*Posts*), pembuatan kategori, integrasi plugin *The Post Grid*, serta perakitan halaman beranda interaktif.



#### 13. Pertemuan 16: Ujian Akhir Semester (UAS)

* **Capaian yang Diharapkan:** Mahasiswa mampu merancang dan mendemonstrasikan proyek akhir pembuatan situs web bisnis/pariwisata digital secara profesional menggunakan CMS WordPress.


* **Materi:** Evaluasi proyek akhir secara menyeluruh (Manajemen CMS, Elementor, Konten, dan Integrasi Sistem).
